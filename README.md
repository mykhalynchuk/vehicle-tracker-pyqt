# Система детекції об’єктів у відео (машинний зір)

### Опис проєкту
Цей проєкт — це система аналізу відео, яка визначає рухомі об’єкти та виділяє серед них автомобілі. 
Програма працює з чорно-білим відео та використовує методи віднімання фону (background subtraction) і аналізу контурів.

**Основна мета** — створити стабільну систему для детекції рухомих об’єктів у реальному часі або з відеофайлу.

### Функціонал
* Завантаження відеофайлу у різних форматах.
* Автоматичне перетворення відео в градації сірого (grayscale).
* Виявлення руху за допомогою алгоритму Background Subtraction.
* Фільтрація об’єктів за розміром і формою (відсікання шуму).
* Інтелектуальне визначення автомобілів.
* Візуалізація: малювання рамок та підписів поверх об’єктів.
* Показ FPS (швидкість обробки кадрів).
  Керування відтворенням:
    - Play / Pause
    - Stop
    - Повзунок для зручної перемотки.

### Як працює система
1.  Відео завантажується та переводиться в grayscale.
2.  Використовується Background Subtraction для пошуку руху.
3.  Застосовується Gaussian Blur для зменшення шуму на масці.
4.  Виконується пошук контурів за допомогою методів OpenCV.
5.  Об’єкти фільтруються за:
    - Площею: щоб прибрати дрібний шум.
    - Пропорціями: пошук форм, що характерні для автомобілів.
6.  На вихідний кадр накладаються прямокутники та підписи.

### Технології
* Python 3.12
* OpenCV (cv2) — основна обробка відео та зображень.
* PyQt6 — сучасний графічний інтерфейс.
* NumPy — робота з масивами та масками.


### Архітектура
Проєкт використовує багатопотоковість для забезпечення плавності інтерфейсу:

1.  Основний потік (GUI): відповідає за кнопки, повзунок та взаємодію з користувачем.
2.  Другий потік (QThread):виконує важку математичну обробку відео та детекцію об’єктів.

Це дозволяє програмі не зависати під час аналізу складних кадрів.

###  Як запустити

1.  **Встановити залежності:**
    ```bash
    pip install opencv-python PyQt6 numpy
    ```
2.  **Запустити програму:**
    ```bash
    python main.py
    ```
3.  Натиснути **Load Video** та вибрати файл.
4.  Використовувати кнопки **Play/Pause** та **Stop** для керування.



### Можливі покращення
* Використання нейромереж (**YOLO**) для точнішої класифікації об'єктів.
* Додавання трекінгу об’єктів (Tracking) для підрахунку машин.
* Підтримка стрімінгу з камери в реальному часі.
* Функція збереження результатів аналізу у файл.
